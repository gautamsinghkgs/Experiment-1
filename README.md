🧪 Experiment-1 — Fullstack Project

Student Registration ● Banking Interface ● Admin Dashboard
A simple fullstack web project demonstrating basic UI workflows including user/student registration, banking interactions, and an admin dashboard interface.

📌 Overview

This repository contains the code for Experiment-1, a fullstack web application built as part of a lab/course project. It includes:

✔ Student registration form
✔ Interactive banking interface (mock UI)
✔ Admin dashboard UI
✔ Responsive frontend pages using HTML & CSS

Live Demo: https://projectexp-1-dashboard.netlify.app/

🚀 Features
🧑‍🎓 Student Registration

• Input form for entering student details
• Basic form fields: Name, Email, Contact, etc.
• Frontend validation (UI)

💳 Banking Interface

• Mock banking UI for user-centric interactions
• Buttons/sections that simulate transactions (UI only)

📊 Admin Dashboard

• Dashboard layout for admin role
• Navigation to major sections: Registration, Banking, Reports

📁 Frontend Files

• index.html – Main entry point
• Supporting CSS files for layout and styling

🛠 Tech Stack

✔ HTML5 – Structure & content
✔ CSS3 – Styling & layout
✔ (No backend logic included — purely UI & frontend experiment)
